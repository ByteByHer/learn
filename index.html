DevOps Beginner Roadmap

Founder of ByteByHer : Sohana Akbar

Suggested pace: 1.5–2 hours daily

Estimated timeline: 3.5–4.5 months

Progress Tracker

Step 1: Linux Fundamentals
Estimated Time: 2–3 weeks

What you will learn

  • Essential Linux commands
  • File system structure and permissions
  • Users, groups, and processes
  • Package management
  • Basic shell scripting

Best Free Resources

  • NetworkChuck – Linux for Beginners (YouTube)
  • freeCodeCamp – Linux Full Course
  • OverTheWire Bandit (hands-on practice)

Hands-on Practice

  • Install Ubuntu (VirtualBox recommended)
  • Practice 10–15 commands daily
  • Write simple bash scripts

Common Mistake

Only memorizing commands without regular practice.

Tip: Linux feels boring at first, but consistency builds real confidence. This is your foundation.
Step 2: Git & GitHub
Estimated Time: 1–1.5 weeks

What you will learn

  • Core Git commands
  • Branching and merging
  • Creating repositories on GitHub
  • Pull Requests

Best Free Resources

  • freeCodeCamp – Git and GitHub for Beginners
  • Official Git documentation (basics)

Hands-on Practice

  • Create your first GitHub repository
  • Upload your Linux notes
  • Make daily commits

Common Mistake

Learning Git and then stopping. You need to use it regularly.

Tip: Git will save you countless hours later. Learn it properly now.
Step 3: Docker
Estimated Time: 3–4 weeks

What you will learn

  • Containers vs Virtual Machines
  • Docker images and containers
  • Writing Dockerfiles
  • Docker Compose
  • Volumes and basic networking

Best Free Resources

  • TechWorld with Nana – Docker Tutorial
  • Play with Docker (browser-based practice)
  • Official Docker Get Started guide

Hands-on Practice

  • Dockerize a simple application
  • Run a multi-container app using Docker Compose

Common Mistake

Watching tutorials without writing your own Dockerfiles.

Tip: Docker is one of the most valuable skills that sets you apart. Give it proper time.
Step 4: Basic CI/CD with GitHub Actions
Estimated Time: 2 weeks

What you will learn

  • What CI/CD actually means
  • GitHub Actions basics
  • Creating simple pipelines
  • Automatically building Docker images

Best Free Resources

  • TechWorld with Nana – GitHub Actions
  • Official GitHub Actions documentation

Hands-on Practice

  • Add a GitHub Actions pipeline to your Docker project

Common Mistake

Jumping straight into complex tools like Jenkins. Start with GitHub Actions.

Tip: Once you understand CI/CD, you’ll start thinking like real engineering teams.
Step 5: AWS Fundamentals
Estimated Time: 3–4 weeks

What you will learn

  • Core cloud concepts
  • EC2, S3, and IAM
  • Security Groups and basic networking
  • Using AWS Free Tier safely

Best Free Resources

  • AWS Skill Builder (free courses)
  • freeCodeCamp – AWS Cloud Practitioner course

Hands-on Practice

  • Launch an EC2 instance
  • Create an S3 bucket
  • Host a simple website on S3

Common Mistake

Crossing Free Tier limits and getting unexpected bills. Always set billing alerts.

Tip: Cloud can feel overwhelming at first. Move slowly but stay consistent.
Step 6: Mini Project
Estimated Time: 2–3 weeks

Project Goal

Build a simple web application → Dockerize it → Set up GitHub Actions for automatic builds → Deploy it on AWS EC2.

This project will become the strongest part of your portfolio.

Tip: A roadmap without a project is incomplete. This is where real learning happens.

If you follow this roadmap with consistency, you will build a solid foundation in DevOps.

Go slow, but don’t stop.
